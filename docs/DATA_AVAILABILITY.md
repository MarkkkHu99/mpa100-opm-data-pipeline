# Data availability

The public repository does not include the real OPM/TXT pair or derived channel
reports used for the saved cross-format and end-to-end evaluation. Although the
reviewed files did not contain a direct student identifier, permission to release
laboratory instrument files publicly has not been established. For 0.9.1 those
data-dependent cases were therefore not re-run; the saved 0.9.0 figures remain
the recorded result.

The repository therefore includes:

- data-independent regression tests;
- the parser and evaluation code;
- redacted, machine-readable result summaries; and
- instructions for an authorised reviewer to rerun the evaluation with a local
  pair placed under `data-private/`.

The following are not available for unrestricted public reuse unless separately
authorised:

- student experimental data;
- original laboratory OPM/TXT files;
- instrument files that expose operational or asset identifiers; and
- reports derived from restricted laboratory inputs.

Code licensing and data licensing are separate decisions. Adding an open-source
software licence must not be interpreted as releasing laboratory data.
