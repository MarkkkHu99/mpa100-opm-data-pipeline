# Contributing

This repository is currently a dissertation research snapshot rather than an
open contribution project. Issue reports and review comments should identify:

1. the software version or commit;
2. the operating system and Python version;
3. the exact command that was run;
4. whether the input was OPM or TXT; and
5. the observed and expected behaviour.

Do not attach student-identifiable data or laboratory files without confirmed
release permission. A minimal synthetic example is preferred when it can
reproduce the issue.

Changes should preserve the evidence boundary between run-level, channel-level
and student-level information. They should also include a regression test when
the change corrects a reproducible defect.
